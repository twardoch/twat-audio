# Contributing

## Development Setup

```bash
git clone https://github.com/twardoch/twat-audio
cd twat-audio
uv venv --python 3.12
uv pip install -e ".[dev,test]"
```

## Running Tests

```bash
python -m pytest tests/ -v
```

## Linting and Formatting

```bash
ruff check src/twat_audio tests
ruff format src/twat_audio tests
```

## Type Checking

```bash
mypy src/twat_audio
```

## Pre-commit Hooks

```bash
pre-commit install
pre-commit run --all-files
```

## Adding a New Operation

1. Add the ffmpeg helper to `src/twat_audio/operations.py` following the existing pattern (accept `str | Path`, return `CommandResult`, support `dry_run`).
2. Add a `_<name>` private function in `src/twat_audio/__main__.py` and register it in `COMMANDS`.
3. Add an entry point in `pyproject.toml` `[project.scripts]`.
4. Add tests in `tests/test_audio_operations.py` using `dry_run=True` for the command-construction tests.
5. Document the new command in `src_docs/user-guide/cli-reference.md` and the API in `src_docs/user-guide/api-reference.md`.

## Project Layout

```
src/twat_audio/
  __init__.py       — public API re-exports and __all__
  __main__.py       — Fire CLI dispatcher
  __version__.py    — generated by hatch-vcs; do not edit
  twat_audio.py     — Pedalboard resampling (AudioProcessConfig, resample_audio)
  operations.py     — ffmpeg-backed helpers (normalize, trim, extract, replace, effect)
  ffmpeg.py         — low-level subprocess wrappers (run_command, run_ffmpeg, probe_audio)
  genai.py          — optional twat_genai adapter
  py.typed          — PEP 561 marker

tests/
  conftest.py               — sys.path setup for src layout
  test_twat_audio.py        — Pedalboard resampling tests
  test_audio_operations.py  — ffmpeg command-construction tests (dry_run)
  test_cli.py               — CLI smoke tests via subprocess
```
